# Worldmind v0.1.0

## Release notes

Worldmind v0.1.0 is the first server-first Fabric release for Minecraft 1.20.1
and Java 17. It provides public-chat observation, bounded direct/ambient
participation, custom/OpenRouter/direct-DeepSeek presets, SQLite world memory,
operator inspection/export/deletion, migrations, privacy redaction, and a
bounded public game-context extension API.

Compatibility: Fabric, Minecraft 1.20.1, Java 17, Linux/macOS/Windows. Dedicated
servers require no Worldmind client mod; integrated hosts use the same common
logical-server path and expose no client entrypoint/UI/protocol. Licensing is
Apache-2.0.

Schema versions are independent: global config v3, profile v1, storage v2, and
memory export v1. The release assets include integrity hashes and metadata.

Not included: AI entities, pathfinding, construction, world/inventory actions,
Minecraft command/tool execution, TTS/STT, web search, embeddings/vector DB,
streaming, a client mod/GUI, non-Fabric loaders, non-1.20.1 support, or personal
modpack knowledge.
